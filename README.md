# Letta 🌐

Чеченское слово "Letta" означает "подключен". Это простой индикатор подключения к интернету на Go.

## 🎯 Цель
Первый проект на Go после 5 лет работы с Python. Учимся основам Go на практике.

## 📦 Функциональность
- Проверка интернет-соединения через HTTP запросы
- Циклическая проверка каждые 5 секунд
- Простой вывод статуса в консоль

## 🚀 Установка и запуск
```bash
# Клонирование
git clone https://github.com/ТВОЙ_НИК/letta.git
cd letta

# Запуск
go run main.go
