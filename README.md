# Letta 🌐

Чеченское слово "Letta" означает "подключен". Это Menu Bar приложение для macOS, которое показывает статус интернет-соединения.

## 🎯 Цель
Первый проект на Go после многолетнего опыта работы с Python. Учимся основам Go на практике.

## 📦 Функциональность
- Проверка интернет-соединения через TCP к личному VPS серверу
- Циклическая проверка **каждую секунду** (быстрый отклик)
- Иконка в строке меню macOS с индикацией статуса:
  - `🌐` — запуск/проверка
  - `✅` — интернет подключен
  - `❌` — нет подключения
- Меню с текущим статусом и кнопкой выхода

## 🚀 Установка и запуск

```bash
# Клонирование
git clone https://github.com/azamuray/letta.git
cd letta

# Установка зависимостей
go mod download

# Сборка
make build

# Запуск
./letta
